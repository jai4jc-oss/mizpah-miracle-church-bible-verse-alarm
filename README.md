# Mizpah Miracle Church Bible Verse Alarm

A daily Bible verse and prayer alarm app built with Expo React Native for Android and iPhone.

Features
- NKJV verse of the day
- Daily alarm time with on/off toggle
- Verse and prayer spoken aloud with voice settings
- Custom morning prayer input
- Church-branded home screen for daily encouragement

Requirements
- Node.js 18+
- Expo CLI
- iOS Simulator or Android Emulator, or the Expo Go app on a phone

Install
1. Open a terminal in the project folder.
2. Run:
   npm install
3. Start the app:
   npx expo start

Run on device
- Android: open the app in Expo Go or run an Android emulator.
- iPhone: open the app in Expo Go or run the iOS simulator.

Notes
- For the alarm notification to work properly, allow notifications on your device.
- The app uses the New King James Version (NKJV) for daily scripture.
